# 簡易版 vs 進階版（給使用者看的版本，訪談最後一題照念）

> 查證與實測日期 2026-10-05。簡易版依賴 Claude 網頁版的排程任務與 Gmail 連接器，功能之後可能改變；每次改版前重查。

| | 簡易版：網頁排程（建議多數人用） | 進階版：雲端程式 |
| :-- | :-- | :-- |
| 一句話 | 在 Claude 網頁版連上 Gmail、建一個排程就好 | 自己架一套程式，在雲端定時跑 |
| 能做什麼 | 摘要報告＋自動分類＋貼小幫手專用標籤 | 摘要報告＋自動分類＋貼小幫手專用標籤 |
| 建置步驟 | 4 步：連 Gmail、完成訪談、建排程並手動跑一次、改成定時 | 7 步：Google Cloud 建憑證、完成訪談、取 token、開 GitHub 私人 repo、建雲端 routine、設環境變數、測試 |
| 建置時間 | 約 10 到 15 分鐘 | 約 1 到 2 小時，第一次多半卡在 Google Cloud |
| 要會什麼 | 會用瀏覽器就好 | 照手冊操作，不用會寫程式，但要不怕陌生名詞 |
| 要裝什麼 | 不用裝任何東西 | Python（只用一次）、GitHub 帳號 |
| 信箱授權方式 | Google 官方登入畫面，隨時可在 Claude 設定裡中斷 | 自己保管一組憑證，等於信箱鑰匙 |
| 安全把關 | 靠排程指示裡寫明的禁止事項；排程用「自動核准」執行 | 程式本身只允許白名單內的收件人與標籤，超出就報錯 |
| 改規則 | 重新貼一次排程指示 | 重新上傳 GitHub＋更新 routine 指示 |
| 一天多場 | 每個時間各建一個排程 | 一個 routine 設多個時間 |
| 成熟度 | 2026-10-05 用測試信箱驗證：排程任務裡讀信、貼標籤、撕標籤皆可行；長期定時執行還在觀察 | 已實際運作中（第一個信箱 2026-07 起、第二個信箱 2026-09 起） |
| 適合誰 | 想快速開始、不想碰技術設定的人 | 想要程式層級的把關、要自訂報告版型、或單位不開放連接器的人 |

**兩個版本共用**：訪談答案、工作脈絡、分類規則。之後要換版本不用重答。

## 怎麼選

```
先用簡易版。
遇到下面任何一種情況，再考慮進階版：
   ├─ 單位的信箱不允許連接 Claude 的 Gmail 連接器
   ├─ 想要「程式強制擋下」白名單以外的收件人與標籤，不只靠指示約束
   └─ 想要固定版型的 HTML 報告，或同一個信箱要寄給多位同事各一份
```

## 有人問再講的細節

- 簡易版的 Gmail 連接器由 Google 提供，工具包含讀信、建立標籤、貼標籤、撕標籤、建草稿、寄信等。小幫手的排程指示只允許其中的讀信、貼「小幫手/」開頭的標籤，以及寄報告給使用者本人；其餘都列為禁止事項。
- 簡易版排程的權限設定是「自動核准」，意思是執行時不會停下來問你。所以排程指示一定要用起始包產出的版本，不要自己加上「順便幫我回信」之類的要求。
- Claude 桌面 app 的 Code 分頁排程，2026-10-05 實測拿不到 Gmail 連接器，所以簡易版請用網頁版的 Scheduled。
- 上一版文件寫過「連接器不能貼標籤」，那是 2026-09 底的狀況，已經過時。
