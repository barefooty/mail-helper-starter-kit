# 路線 1 vs 路線 3 利弊（給使用者看的版本，訪談路線題照念）

> 查證日期 2026-09-29。路線 3 的限制來自 Claude 官方 Gmail 連接器與排程功能的現況，之後可能改變；每次改版前重查。

| | 路線 1：雲端完整版 | 路線 3：桌面輕量版 |
| :-- | :-- | :-- |
| 一句話 | 小幫手住在雲端，24 小時自己跑 | 小幫手住在你的電腦裡，Claude app 開著才跑 |
| 能做什麼 | 摘要報告＋自動分類＋**貼標籤到信上**＋（選）擬草稿 | 摘要報告＋自動分類＋（選）擬草稿；**標籤只寫在報告裡建議，不貼到信上** |
| 電腦關機時 | 照跑 | 不跑，下次開機補跑 |
| 建置步驟 | 7 步：Google Cloud 建憑證、裝 Python、取 token、開 GitHub 私人 repo、建雲端 routine、設環境變數、測試 | 3 步：在 Claude 設定連 Gmail、拖資料夾進 Cowork、設桌面排程 |
| 建置時間 | 約 1～2 小時，第一次多半卡在 Google Cloud | 約 10 分鐘 |
| 要會什麼 | 照手冊操作，不用會寫程式，但要不怕陌生名詞 | 會用 Claude app 就好 |
| 資安 | AI 拿到信箱憑證（可加遮罩降低）；憑證存在自己的 GitHub 私人 repo 與 routine 環境變數 | 授權走 Google 官方登入，沒有憑證檔可外流；AI 一樣讀得到信全文 |
| 用量 | 消耗自己 Claude 訂閱的雲端用量 | 消耗自己 Claude 訂閱的用量 |
| 適合誰 | 信量大、要靠標籤在 Gmail 裡篩、想全自動 | 想先試試看、信量中等、每天本來就開著 Claude |
| 之後升級 | 已是完整版 | 訪談產出的規則直接沿用，補做 7 步即升級 |
| 成熟度 | 已實際運作一年以上（兩個信箱） | **實測中**：桌面排程能否穩定讀 Gmail 尚待驗證 |

## 為什麼路線 3 不能貼標籤（有人問再講）

Claude 內建的 Gmail 連接器目前有：搜尋、讀信、建草稿、回信、寄信、建立標籤與過濾器；**沒有「把標籤貼到某封信」的工具**（官方功能請求 anthropics/claude-code#36547，尚未實作）。另外雲端排程目前拿不到連接器（#42033、#43397），所以路線 3 只能用桌面排程，電腦要開著。
