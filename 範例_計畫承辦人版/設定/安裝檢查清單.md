# 安裝檢查清單（小禾，簡易版：網頁排程）

> 精靈已產好 `網頁排程指示.md`；以下是**你本人**要做的步驟，共 4 步（連信箱→建排程手動跑一次→看標籤與報告→改定時），約 15 分鐘。每步寫了「這步是為了」與「怎麼確認做對了」，做完打勾。

| # | 做什麼 | 這步是為了 | 怎麼確認做對了 | 卡住時看哪裡 |
| :-- | :-- | :-- | :-- | :-- |
| 0 | （選做）不想自己點的話：照 `說明圖/Claude擴充功能_安裝與綁定.png` 在 Chrome 裝好 Claude 擴充功能並綁定自己的帳號，之後第 1、2、5 步改成對 Claude 說「幫我做安裝步驟」；跳出 Google 登入或允許畫面時換你本人操作 | 之後第 1、2、5 步可以讓 Claude 替你點，你只負責登入 | Chrome 工具列看得到 Claude 圖示，點開是自己的帳號 | 手冊步驟 0 |
| 1 | 開 claude.ai → Customize → Connectors → Gmail 按「＋」，用 xiaohe@my-school.edu.tw 完成 Google 授權 | 小幫手要能讀信、貼標籤、寄報告，所以 Claude 需要你授權連這個信箱 | 新對話問「目前連接的信箱地址」，回答是這個信箱 | `簡易版_網頁排程/安裝手冊.md` 步驟 1 |
| 2 | claude.ai → Scheduled → New task → Set up manually：名稱「信箱小幫手 08:00」、Instructions 貼上 `網頁排程指示.md` 的指示全文、Frequency 先選 Manual → Save → Run now | 排程＝每天自動跑的那個「人」；指示＝它的工作規則。先手動跑一次是看結果對不對 | History 多一筆；報告分類合理；收件匣收到【信箱報告】；Gmail 裡的信仍是未讀 | 手冊步驟 3 |
| 3 | 到 Gmail 看標籤 | 確認它只動「小幫手/」標籤、沒碰你原本的標籤 | 左側多了「小幫手」，底下有「已整理」等子標籤；自己原本的標籤沒變。上層的「小幫手」是 Gmail 自動產生的，屬正常 | 手冊「標籤的小提醒」 |
| 4 | 報告不合理就回起始包說「補充：…」，重貼 Instructions 再 Run now | 分類規則是照你講的做的，不合理就補充，它會重產指示 | 第二次報告符合預期 | 精靈第五節補充流程 |
| 5 | 編輯排程：Frequency 改 Weekdays、時間 08:00；再建一個一樣的排程設 14:00 | 滿意了才讓它定時跑，之後電腦關機也照寄 | 排程清單顯示兩個時間；時間到 History 有新紀錄 | 手冊步驟 4 |
| 6 | 一週後回頭看「該來沒來」有沒有誤報 | 「該來沒來」靠你填的日期，日期錯會誤報 | 誤報就改 `專案階段表.xlsx` 的日期，說「重新讀工作脈絡」，再重貼指示 | 精靈第三節 |
