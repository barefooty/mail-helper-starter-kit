# 設定/（訪談後才會有東西）

精靈訪談完會把你的設定產在這裡：

| 檔案 | 用途 | 路線 |
| :-- | :-- | :-- |
| config.json | 主旨前綴、收件人白名單、標籤設定 | 共用 |
| report_template.html | 報告版型（已換好配色） | 共用 |
| routine-prompt.md | 貼進雲端 routine 的 prompt | 路線 1 |
| 路線1_上傳包/ | 要上傳到 GitHub 私人 repo 的全部檔案（程式＋設定，已放在同一層） | 路線 1 |
| 桌面排程prompt.md | 貼進桌面排程任務的 prompt | 路線 3 |
| 上次掃描時間.txt | 進度基準，自動維護，不要手改 | 路線 3 |
| 安裝檢查清單.md | 你本人要做的步驟與確認方式 | 依路線 |

要分享起始包給別人前，把這個資料夾清空（留本檔即可）。
