# 設定/（訪談後才會有東西）

精靈訪談完會把你的設定產在這裡：

| 檔案 | 用途 | 版本 |
| :-- | :-- | :-- |
| 網頁排程指示.md | 貼進 Claude 網頁版排程任務 Instructions 欄位的整段指示（已含你的分類規則） | 簡易版 |
| 安裝檢查清單.md | 你本人要做的步驟與確認方式 | 兩個版本都有 |
| config.json | 主旨前綴、收件人白名單、標籤設定 | 進階版 |
| report_template.html | 報告版型（已換好配色） | 進階版 |
| routine-prompt.md | 貼進雲端 routine 的指示 | 進階版 |
| 進階版_上傳包/ | 要上傳到 GitHub 私人 repo 的全部檔案（程式＋設定，已放在同一層） | 進階版 |

要分享起始包給別人前，把這個資料夾清空（留本檔即可）。
