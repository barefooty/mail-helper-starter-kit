# 簡易版：網頁排程 安裝手冊

> 預估時間：10 到 15 分鐘。只需要瀏覽器，不用安裝任何程式、不用申請憑證。
> 需要：自己的 Claude 付費帳號、要整理的 Google 信箱（Gmail 或學校的 Google Workspace）。
> **實測狀態（2026-10-05，測試信箱）**：連接 Gmail、排程任務讀信與貼標籤已驗證可行。「寄摘要信給自己」與長期定時執行的穩定度還在觀察，遇到跟手冊不一樣的地方請回報。

## 開始前請確認

- 用**自己的** Claude 帳號。Gmail 一旦連上，用同一個 Claude 帳號的人都能透過 Claude 讀寫這個信箱，所以個人信箱不要連到多人共用的 Claude 帳號。
- 學校或機關的信箱若在步驟 1 被「管理員封鎖」擋下，代表該單位不開放第三方連接，請洽資訊單位，或先用測試用的 Gmail 試。

## 步驟 1｜連接 Gmail（3 分鐘）

1. 開 https://claude.ai ，左側選單點 **Customize**，再點 **Connectors**。
2. 找到 **Gmail**，按右邊的「＋」。
3. 第一次使用 Gmail 時，Claude 會顯示需要驗證，按 **Connect**，在跳出的 Google 視窗選要整理的信箱，按允許。

怎麼確認做對了：在 Claude 開一個新對話，輸入「用 Gmail 連接器告訴我目前連接的信箱地址，不要做任何更動」。回覆的地址是你要整理的那個信箱，就成功了。

## 步驟 2｜先完成訪談（5 分鐘）

還沒做的話，把起始包資料夾交給 Claude（Cowork 或 Claude Code），說「開始建置」，路線選簡易版。精靈會在 `設定/` 產出 `網頁排程指示.md`，裡面已經填好你的分類規則。

怎麼確認做對了：`設定/網頁排程指示.md` 打開看得到你的業務線與往來對象，沒有殘留的【】佔位。

## 步驟 3｜建立排程並先手動跑一次（5 分鐘）

1. 在 claude.ai 左側選單點 **Scheduled**，右上按 **New task**，選 **Set up manually**。
2. **Name**：取一個看得懂的名字，例如「信箱小幫手」。
3. **Instructions**：打開 `設定/網頁排程指示.md`，把「指示全文」以下整段複製貼上。
4. **Frequency**：先選 **Manual**。
5. **Permissions**：維持 Automatically approve，排程才不會停下來等你按同意。
6. 按 **Save**，進到這個排程的頁面，按右上 **Run now**。
7. 等一兩分鐘，點 History 裡那一筆，看它的回覆。

怎麼確認做對了：
- 報告的分類看起來合理。
- 回到 Gmail：信還是未讀；除了「小幫手/」開頭的標籤，其他標籤都沒被動到。沒開貼標籤的話，信箱應該完全沒變。
- 有設定寄報告的話，收件匣收到一封主旨以你設定的前綴開頭的信。

分類不合理：回到起始包跟 Claude 說「補充：……」，它會重產 `網頁排程指示.md`，再回來把 Instructions 整段換掉，重跑一次。

## 步驟 4｜改成定時執行

1. 在排程頁面按鉛筆圖示編輯。
2. **Frequency** 改成 Weekdays 或 Daily，旁邊設定時間。一天要跑兩三次，就複製成兩三個排程，各設不同時間。
3. 展開 **Advanced settings**，想在跑完時收到通知可勾 Email。
4. 按 Save。

怎麼確認做對了：排程清單上顯示你設定的時間；時間到之後 History 多一筆紀錄。

## 日常維護速查

| 狀況 | 處理 |
| :-- | :-- |
| 改分類規則、窗口換人 | 回起始包說「補充：……」重產指示，再到排程把 Instructions 整段換掉 |
| 報告重複列同一封信 | 沒開貼標籤時是正常的重疊保險；想避免就開啟貼標籤，靠「小幫手/已整理」防重複 |
| 排程沒跑 | 到 Scheduled 頁面看該排程是不是 Active、History 有沒有錯誤訊息 |
| 回覆寫「沒有 Gmail 工具」或「需要驗證」 | 回步驟 1 重新連接 Gmail |
| 想暫停 | 把 Frequency 改回 Manual |
| 不想用了 | 刪除排程（執行紀錄會一起刪除，無法復原）；Customize 的 Connectors 裡中斷 Gmail；到 Gmail 把「小幫手」標籤與底下的子標籤刪掉 |
| 想要更完整的控制 | 改用進階版，訪談答案沿用 |

## 標籤的小提醒

- 小幫手只會用「小幫手/」開頭的標籤，例如「小幫手/已整理」「小幫手/跨校選課計畫」。
- Gmail 會自動多出一個上層標籤「小幫手」，底下收著所有子標籤，這是正常的。
- 你自己手動貼的標籤，小幫手不會碰。
