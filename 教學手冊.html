一、它會幫你做什麼、不會做什麼

會做（每天固定時間，例如 8:00 與 14:00）

  • 看新進的信，含垃圾信匣裡疑似漏掉的
  • 依你的工作分類：哪個專案、哪個階段、誰寄的、急不急
  • 整理成一份摘要報告：還沒回的排前面、附一句建議
  • 提醒「該來沒來」：時間到了還沒收到的名單或文件
  • 你允許的話，在 Gmail 幫信貼上「小幫手/」開頭的專用標籤

不會做（永遠不會）

  • 替你回信、寄信給別人
  • 動你手動貼的標籤、把信標成已讀、刪信、移動信件
  • 替你擬回信草稿（這一版不提供）

二、四步建置

  1. 把整個資料夾拖進 ClaudeCowork 或 Claude Code 都可以。Claude 主動說「這是信箱小幫手起始包，準備好就說『開始建置』」。
  2. 說「開始建置」，回答 8 題（約 5 分鐘）每題有選項，也可以自己講；第 4、5 題可以用兩張 Excel 代替口述。Claude 把產出的檔案逐項念給你確認。
  3. 到 Claude 網頁版連上 Gmail、建一個排程把它產出的「網頁排程指示」整段貼進去。排程建立成功，出現在 Scheduled 清單。
  4. 先手動跑一次，滿意後改成定時看報告合不合理，不滿意就回來說「補充：…」再改。報告的分類符合你的工作；Gmail 裡的信還是未讀。
訪談與產出設定完全不需要信箱權限。連信箱與建排程由你本人操作。

三、要準備的兩張 Excel（先填幾列就好）

在 我的工作脈絡/ 裡，每張都有範例列與「填寫說明」分頁。範例列的備註寫著「範例，請刪除」，填自己的資料後把它刪掉。

email對方的信箱或網域認出寄件人，歸到對的專案

欄位填什麼小幫手拿來做什麼

這兩張表只在你的電腦使用。email 只用來辨識寄件人，習慣欄只用來加提醒。不要把學生個資放進來。

五、兩個版本怎麼選

簡易版：網頁排程 建議進階版：雲端程式
一句話在 Claude 網頁版連上 Gmail、建一個排程就好自己架一套程式，在雲端定時跑
能做什麼摘要報告＋分類＋貼標籤摘要報告＋分類＋貼標籤
建置4 步，約 10 到 15 分鐘7 步，約 1 到 2 小時
要會什麼會用瀏覽器就好照手冊操作，不用會寫程式，但要不怕陌生名詞
要裝什麼不用裝任何東西Python（只用一次）、GitHub 帳號
信箱授權Google 官方登入畫面，隨時可在 Claude 設定裡中斷自己保管一組憑證，等於信箱鑰匙
安全把關靠排程指示裡寫明的禁止事項程式只允許白名單內的收件人與標籤，超出就報錯
成熟度2026-10-05 以測試信箱驗證：排程裡讀信、貼標籤可行；長期定時執行還在觀察已實際運作中（2026-07 起）
適合誰多數人想要程式層級把關、自訂報告版型，或單位不開放連接器的人
先用簡易版。
遇到下面任何一種情況，再考慮進階版：
   ├─ 單位的信箱不允許連接 Claude 的 Gmail 連接器
   ├─ 想要「程式強制擋下」白名單以外的收件人與標籤，不只靠指示約束
   └─ 想要固定版型的 HTML 報告，或同一個信箱要寄給多位同事各一份

訪談答案兩個版本共用，之後要換不用重答。

六、簡易版安裝步驟（網頁排程）建議

需要：自己的 Claude 付費帳號、要整理的 Google 信箱。只用瀏覽器，不用安裝任何程式。完整細節見 簡易版_網頁排程/安裝手冊.md。

  1. 連接 Gmail開 claude.ai，左側 Customize，再點 Connectors，找到 Gmail 按「＋」。第一次使用時按 Connect，在 Google 視窗選要整理的信箱並允許。開新對話問「目前連接的信箱地址」，回答是你要整理的那個信箱。
  2. 完成訪談就是第二節的前兩步，版本選簡易版。設定/網頁排程指示.md 看得到你的業務線，沒有殘留的【】。
  3. 建立排程，先手動跑一次claude.ai 左側 Scheduled，New task，Set up manually。Instructions 貼上指示全文，Frequency 先選 Manual，Save 後按 Run now。History 多一筆；報告分類合理；Gmail 裡的信還是未讀；除了「小幫手/」開頭的標籤，其他標籤都沒被動到。
  4. 改成定時編輯排程，Frequency 改 Weekdays 或 Daily 並設時間。一天要跑兩三次，就各建一個排程。排程清單顯示你設定的時間；時間到之後 History 多一筆。
開了貼標籤後，Gmail 左側會多一個「小幫手」，底下收著「已整理」與各業務線的子標籤。上層的「小幫手」是 Gmail 自動產生的，屬正常現象。
排程用「自動核准」執行，不會停下來問你。指示請用起始包產出的版本，不要自己加上「順便幫我回信」之類的要求。

七、進階版安裝步驟（雲端程式）

需要：自己的 Claude 付費帳號、自己的 GitHub 帳號（免費版）、要整理的 Google 信箱、一台有 Python 3 的電腦（只在步驟 3 用一次）。完整細節見 進階版_雲端程式/安裝手冊.md。

  1. Google Cloud 建 OAuth 憑證用要整理的信箱登入 console.cloud.google.com：新增專案，啟用 Gmail API，OAuth 同意畫面選外部並發布為正式版，建「電腦版應用程式」憑證。拿到用戶端 ID 與用戶端密碼；發布狀態顯示「正式版」（停在測試中，授權 7 天就失效）。
  2. 完成訪談版本選進階版，精靈會產出設定與上傳包。設定/ 裡有 config.json、routine-prompt.md、report_template.html 與 進階版_上傳包/。
  3. 取得 refresh token在 進階版_雲端程式/ 開終端機跑 get_refresh_token.py，瀏覽器登入要整理的信箱、允許。終端機印出 GMAIL_REFRESH_TOKEN=…，抄起來，這串等於信箱鑰匙。
  4. 推上自己的 GitHub 私人 repogithub.com 新增 repository，選 Private，把 設定/進階版_上傳包/ 裡的檔案全部拖上去。repo 顯示 Private；沒有上傳 .env 或任何含 token 的檔案。
  5. 建雲端 routineclaude.ai/code 的 Routines 新增：貼 routine-prompt.md 的指示全文、連接 repo、設 cron（UTC＝台灣時間減 8）、填四個環境變數、Network access 加 gmail.googleapis.com 與 oauth2.googleapis.com。routine 頁面顯示 Active。
  6. 測試按 Run now。收到報告；信箱裡的信仍未讀；若啟用自動標籤，只多了白名單內的標籤。
  7. 不滿意就改對 Claude 說「補充：…」，改完重新上傳 GitHub 並更新 routine 的指示。第二次報告符合預期。
第一次多半卡在步驟 1，Google 的介面常改版。卡住時把畫面截圖給 Claude，它會對照手冊指路。

八、之後怎麼補充、怎麼關掉

想做什麼怎麼做
窗口換人、新增對象改 對接對象清單.xlsx，對 Claude 說「重新讀工作脈絡」；或直接說「補充：○○的窗口換成王小姐」
新增階段、改時間改 專案階段表.xlsx，說「重新讀工作脈絡」
改急件定義、改優先序說「以後廠商報價信算急件」，它只改分類規則
規則改完之後簡易版：到排程把 Instructions 整段換成新的指示。進階版：重新上傳 GitHub 並更新 routine 的指示
換版本說「換成進階版」或「換成簡易版」，訪談答案沿用
排程沒跑、報告沒來簡易版：到 Scheduled 看排程是不是 Active、History 有沒有錯誤。進階版：routine 頁面看 Runs，可 Run now 補發
想暫停簡易版：Frequency 改回 Manual。進階版：關掉 routine 的 Active
不想用了簡易版：刪除排程（執行紀錄會一起刪除）、在 Connectors 中斷 Gmail、到 Gmail 刪掉「小幫手」標籤。進階版：關 routine，到 myaccount.google.com/permissions 移除授權

九、安全與隱私

用自己的帳號

Gmail 連上後，用同一個 Claude 帳號的人都能透過 Claude 讀寫這個信箱。個人信箱不要連到多人共用的 Claude 帳號。

只用專用標籤

小幫手只會新增或移除「小幫手/」開頭的標籤，不碰你手動貼的標籤，也不會把信標成已讀。

資料夾不外傳

我的工作脈絡/ 與 設定/ 是你的工作筆記與聯絡資料。要分享起始包給別人，先把這兩個資料夾清空。

不替你發言

不回信、不寄信給別人、不擬草稿。報告只寄給你自己。進階版的憑證等於信箱鑰匙，不要跟同事共用。
