# 信箱小幫手 起始包

把這個資料夾交給 Claude，回答 8 個問題，它幫你建一個「每天幫你看信、分類、寫摘要」的助理。訪談會問你的工作、專案階段、往來對象與他們的習慣，所以分類是照你的工作量身做的。

目前版本：v0.1.1（測試中，歡迎回報卡關的地方）

## 怎麼開始

1. 按右上綠色的 **Code** → **Download ZIP**，解壓縮到電腦。
2. 用 Claude 桌面 app 的 Cowork（或 Claude Code）開啟解壓後的資料夾。
3. 對它說「**開始建置**」，照著回答就好，約 5 分鐘。

想先看完整說明：下載後雙擊 `教學手冊.html`；只想看一頁版就看 `開始之前請讀我.md`。

## 需要什麼

- 自己的 Claude 帳號（Pro 以上）
- 要掃描的信箱是 Google 帳號（Gmail 或學校的 Google Workspace）
- 路線 1 另外需要自己的 GitHub 帳號與一台有 Python 3 的電腦

## 兩條路線

| | 路線 1：雲端完整版 | 路線 3：桌面輕量版（實測中） |
| :-- | :-- | :-- |
| 一句話 | 住在雲端，24 小時自己跑 | 住在你電腦，Claude app 開著才跑 |
| 能貼標籤到信上 | 可以 | 不行，只在報告裡建議 |
| 建置 | 7 步，約 1～2 小時 | 3 步，約 10 分鐘 |

訪談時會幫你選，答案兩條路共用，之後可以換。

## 它不會做的事

替你回信、寄信給別人、動你手動貼的標籤、標已讀、刪信。預設完全唯讀，你明確允許才會貼它自己的標籤。

## 安全提醒

- 用**自己的** Claude 帳號與信箱；用共用帳號跑，等於把信箱給共用帳號的每個人看。
- 這個公開版不含任何人的真實資料，`範例_計畫承辦人版/` 裡的學校、姓名、信箱全是虛構。
- 你自己填的 `我的工作脈絡/` 與 `設定/` 只留在你的電腦，**不要**上傳到任何公開的地方。
- 路線 1 要放上 GitHub 的檔案，repo 一定要選 Private，且不要上傳 `.env` 或任何含 token 的檔案。

## 回報問題

測試時卡在哪一步、哪一題看不懂、哪裡跟說明不一樣，請告訴提供你這個連結的人。
