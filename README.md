# 信箱小幫手 起始包

把這個資料夾交給 Claude，回答 8 個問題，它幫你建一個「每天幫你看信、分類、貼標籤、寫摘要」的助理。訪談會問你的工作、專案階段、往來對象與他們的習慣，所以分類是照你的工作量身做的。

目前版本：v0.3.6（測試中，歡迎回報卡關的地方）

## 怎麼開始

1. 按右上綠色的 **Code** → **Download ZIP**，解壓縮到電腦。
2. 用 Claude 桌面 app 的 Cowork（或 Claude Code）開啟解壓後的資料夾。
3. 對它說「**開始建置**」。它會先講整趟 4 步（訪談→念產出確認→連信箱建排程→手動跑一次），之後每題、每步都報進度與目的。然後問你想怎麼答：
   - **直接聊**：一題一題答，約 5 分鐘。
   - **先掃信箱再聊**：你同意後，它只讀過去 7 天信件的「統計」（寄件單位、常見主旨、數量；不讀內文、不改信），把看到的預填成選項，你確認就好。
   - **領 Word 問卷慢慢填**：把 `我的工作脈絡/工作脈絡問卷_模板.docx` 複製一份、檔名去掉 `_模板`（或請它產一份預填版），花幾天填（可以查資料、問同事），填完放回來說「讀問卷」。
4. 照它產出的安裝檢查清單，到 Claude 網頁版連上 Gmail、建立排程。

每一場也會另外掃垃圾信匣：學校、合作單位或名單上的人寄來卻被誤判成垃圾信的，報告用紅框提醒你去撈；它不會自己把信移出垃圾信匣。

報告多久寄一次由你在第 7 題（報告時間）決定（預設平日早上一次，也可一天兩三次）。排程在 Claude 的雲端執行，電腦關機也照樣寄；第一次請先手動跑一次確認收得到。

想先看完整說明：下載後雙擊 `教學手冊.html`；只想看一頁版就看 `開始之前請讀我.md`。

## 需要什麼

- 自己的 Claude 付費帳號
- 要整理的信箱是 Google 帳號（Gmail 或學校的 Google Workspace）

## 兩個版本

| | 簡易版：網頁排程（建議） | 進階版：雲端程式 |
| :-- | :-- | :-- |
| 一句話 | 在 Claude 網頁版連上 Gmail、建一個排程 | 自己架一套程式在雲端定時跑 |
| 貼標籤到信上 | 可以 | 可以 |
| 報告長相 | 固定版型的 HTML 信，四套顏色擇一 | 同左，另可自己改整個版型 |
| 建置 | 4 步，約 10 到 15 分鐘，只要瀏覽器 | 7 步，約 1 到 2 小時，要 GitHub 與 Python |

先用簡易版就好。訪談答案兩個版本共用，之後可以換。

## 它不會做的事

替你回信、寄信給別人、動你手動貼的標籤、把信標成已讀、刪信。它只會用「小幫手/」開頭的專用標籤，要不要開啟貼標籤由你決定。訪談本身不碰信箱；只有你選「先掃信箱」時，它才做一次唯讀統計，產出的側寫檔裡只有網域與主旨樣式，沒有信件內容。

## 安全提醒

- 用**自己的** Claude 帳號與信箱。Gmail 連上後，用同一個 Claude 帳號的人都能透過 Claude 讀寫這個信箱，所以個人信箱不要連到多人共用的 Claude 帳號。
- 這個公開版不含任何人的真實資料，`範例_計畫承辦人版/` 裡的學校、姓名、信箱全是虛構。
- 你自己填的 `我的工作脈絡/` 與 `設定/` 只留在你的電腦，**不要**上傳到任何公開的地方。
- 進階版要放上 GitHub 的檔案，repo 一定要選 Private，且不要上傳 `.env` 或任何含 token 的檔案。
- 報告有打碼：指示要求寫摘要前把身分證字號、電話、10 碼以上的數字、帳號密碼遮中間（留頭尾，例 0912○○○○78；密碼留前 2 字（Aa○○○○○○））（簡易版靠模型自律：指示有「隱私硬規則」——人名改 O、號碼換○、不抄原句、寄出前自檢；進階版寄出前另由程式把寄件人人名改「王O明」、號碼再掃一次，不靠自律）；進階版的程式另在讀信時先遮一次同樣的樣式（只遮得到已知樣式）。姓名、地址這類自由文字遮不到，所以報告仍只寄給自己；人事、主計、學生個資這類信可以在訪談第 8 題（授權邊界）設成「只列一行、不寫摘要」，那一行長這樣：「王O明（甲大學）｜退費申請｜10/16 09:12」，姓名中間字改 O、學校照寫、學號打碼。

## 回報問題

測試時卡在哪一步、哪一題看不懂、哪裡跟說明不一樣，請告訴提供你這個連結的人。
