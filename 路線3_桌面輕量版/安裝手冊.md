# 路線 3：桌面輕量版 安裝手冊

> ⚠ **本路線尚在實測階段**（2026-09-29）。以下步驟依 Claude 官方文件設計，實測通過後會把「已驗證」標上去；在那之前遇到卡關請回報。
> 預估時間：10 分鐘。需要：自己的 Claude 帳號（Pro 以上）＋ Claude 桌面 app＋要掃描的 Google 信箱。
> 限制先講清楚：電腦與 Claude app 要開著才會跑；標籤目前先寫在報告裡建議（能否直接貼到信上查證中）。

## 步驟 1｜在 Claude 連接 Gmail（2 分鐘）

1. 開 Claude 桌面 app → 設定 → 連接器（Connectors）→ 找 Gmail → 連接。
2. 用**要掃描的那個信箱**登入 Google，允許授權。
3. 確認方式：連接器清單裡 Gmail 顯示已連接。

## 步驟 2｜把起始包交給 Cowork，跑一次唯讀測試（3 分鐘）

1. 開 Cowork，選這個起始包資料夾當工作資料夾。
2. 對它說：「照 `設定/桌面排程prompt.md` 用唯讀模式跑一輪，不要寄信，報告存到 `報告/`。」
3. 確認方式：`報告/` 裡多出一個 HTML 檔，打開看分類合不合理；信箱裡的信仍是未讀、標籤沒動。
4. 不合理 → 對它說「補充：…」改規則，再跑一次。

## 步驟 3｜設桌面排程（3 分鐘）

1. Claude 桌面 app → 排程任務（Scheduled tasks）→ 新增。
2. 工作資料夾：這個起始包。Prompt：貼上 `設定/桌面排程prompt.md` 的「Prompt 全文」整段。
3. 時間：依訪談（例：平日 08:00 與 14:00）。
4. 確認方式：到時間看 `報告/` 有沒有新檔（若設了寄出，看收件匣）。

## 日常維護速查

| 狀況 | 處理 |
| :-- | :-- |
| 報告沒產生 | 電腦或 Claude app 沒開；開起來後手動跑一次即可，時間窗自動涵蓋空窗 |
| 報告重複列信 | 檢查 `設定/上次掃描時間.txt` 有沒有被改壞；刪掉它會退回抓近 5 天 |
| 改規則 | 改 `我的工作脈絡/` 的 Excel 或直接跟 Claude 說「補充：…」；下一輪自動讀新規則 |
| 想升級路線 1 | 對 Claude 說「換成路線 1」，規則沿用，補走路線 1 安裝手冊 |
| 不想用了 | 刪掉排程任務；設定 → 連接器 → 中斷 Gmail |
